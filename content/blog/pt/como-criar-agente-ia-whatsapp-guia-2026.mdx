## O que é um agente de IA para WhatsApp (e como é diferente de um chatbot)

Essa distinção importa muito para quem vai tomar decisões técnicas e de investimento.

**Chatbot tradicional** = fluxo de regras fixas. O usuário clica em opções pré-definidas, o bot segue um script. Funciona para FAQs simples, mas quebra quando o cliente faz uma pergunta fora do roteiro.

**Agente de IA** = inteligência autônoma. Ele entende linguagem natural, interpreta a intenção do usuário, toma decisões, chama ferramentas externas (CRM, agenda, banco de dados), e age de forma proativa. Não precisa de menus. Conversa como um humano treinado.

A diferença na prática:

| Característica | Chatbot | Agente de IA |
|---|---|---|
| Entende linguagem natural | ❌ | ✅ |
| Responde fora do script | ❌ | ✅ |
| Integra com sistemas externos | Limitado | ✅ Nativo |
| Aprende com o contexto da conversa | ❌ | ✅ |
| Executa ações (agendar, registrar, cobrar) | ❌ | ✅ |
| Custo de manutenção | Alto (atualizar fluxos) | Baixo |

IA agêntica não é buzzword. É a diferença entre um atendente robótico e um colaborador digital que realmente resolve.

## Passo a passo: criando um agente com WhatsApp Business API + IA

Para quem quer implementar no Caminho 2, aqui está o fluxo técnico básico:

### 1. Obtenha acesso à WhatsApp Business API

Você tem duas opções:

**a) Cloud API oficial da Meta (recomendado para produção)**
- Acesse [developers.facebook.com](https://developers.facebook.com)
- Crie um App de negócios
- Habilite o produto WhatsApp
- Verifique o número de telefone comercial
- Custo: gratuito para as primeiras 1.000 conversas/mês iniciadas por usuários

**b) Evolution API (open source, para testes e produção)**
- Clone o repositório: `git clone https://github.com/EvolutionAPI/evolution-api`
- Deploy via Docker em seu servidor
- Conecte via QR Code ou número verificado

### 2. Configure o n8n como orquestrador

```bash
# Via Docker (recomendado)
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -e N8N_BASIC_AUTH_ACTIVE=true \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

No n8n, crie um workflow com:
- **Trigger:** Webhook para receber mensagens do WhatsApp
- **Node OpenAI/Claude:** Processa a mensagem com contexto
- **Node HTTP:** Envia resposta de volta via Evolution API ou Cloud API
- **Node condicional:** Detecta intenções e aciona ferramentas externas

### 3. Integre o LLM com memória de contexto

O segredo de um bom agente é o **contexto persistente**. Configure o n8n para armazenar o histórico da conversa (em Redis ou banco de dados) e incluir no prompt de cada mensagem nova.

Exemplo de prompt do sistema:
```
Você é Maria, assistente virtual da [Empresa]. 
Histórico da conversa: {contexto}
Você pode agendar consultas, responder sobre preços e qualificar leads.
Quando o cliente quiser agendar, colete: nome, data preferida, serviço.
Responda SEMPRE em português, de forma natural e concisa.
```

### 4. Configure o webhook

No painel da sua Evolution API ou Cloud API, configure o webhook para apontar para o endpoint do seu n8n:

```
https://seu-n8n.dominio.com/webhook/whatsapp
```

### 5. Teste e monitore

Antes de apontar para produção, teste com número secundário. Valide:
- Respostas fora do escopo (o agente sabe quando não sabe?)
- Tempo de resposta (deve ser < 3 segundos)
- Comportamento com mensagens de áudio, imagens, documentos
- Escalonamento para humano quando necessário

## Erros comuns ao criar agentes de IA no WhatsApp (e como evitar)

**1. Não definir escopo claro**
O agente tenta fazer tudo e não faz nada bem. Defina: quais perguntas ele responde? Quando escala para humano? Quais ações pode executar?

**2. Ignorar o escalonamento para humano**
Agentes que nunca passam para um atendente real frustram clientes em situações sensíveis. Sempre configure uma saída: "falar com atendente" deve ser opção acessível.

**3. Contexto sem memória**
Cada mensagem tratada como nova conversa cria experiência ruim. Implemente armazenamento de histórico — mesmo uma janela de 10 mensagens já muda tudo.

**4. Não testar com usuários reais**
A IA responde diferente do que você esperava? Normal. Teste com 10 cenários reais antes do lançamento.

**5. Prompt genérico demais**
"Seja um assistente útil" não é instrução para IA de negócios. Quanto mais específico o prompt (empresa, tom, limitações, exemplos), melhor o comportamento.

**6. Violar políticas do WhatsApp**
Enviar mensagens em massa sem opt-in, usar contas não verificadas, ou fazer spam são formas rápidas de ter o número banido. Use a API oficial e respeite as diretrizes.

**7. Lançar sem métricas**
Defina KPIs antes de lançar: taxa de resolução, tempo médio de resposta, taxa de escalonamento, NPS. Sem dados, você não sabe o que melhorar.
