## Pré-requisitos para instalação

Antes de iniciar, verifique que seu servidor atende aos requisitos mínimos:

- **Sistemas suportados**: Ubuntu 20.04+, Debian 11+, CentOS 8+, Windows Server 2019+
- **Recursos mínimos**: 2 vCPUs, 4 GB RAM, 20 GB de armazenamento SSD
- **Dependências**: Python 3.8+, Docker (opcional para containers), Git
- **Acesso**: Permissões de administrador/sudo

Para confirmar a compatibilidade, execute:

```bash
python3 --version
docker --version  # se aplicável
uname -a          # no Linux
```

## Instalação passo a passo no Linux

### 1. Configuração do ambiente

Atualize o sistema e instale as dependências básicas:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip git curl wget
```

### 2. Download e instalação do Hermes Agent

Clone o repositório oficial e entre no diretório:

```bash
git clone https://github.com/hermes-agent/hermes-agent.git
cd hermes-agent
```

Instale as dependências Python:

```bash
pip3 install -r requirements.txt
```

### 3. Configuração do arquivo .env

Crie o arquivo de configuração:

```bash
cp .env.example .env
nano .env   # ou vim, vs code
```

Preencha as variáveis essenciais:

- `HERMES_API_KEY=your_api_key_here`
- `DATABASE_URL=postgresql://user:pass@localhost:5432/dbname`
- `SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...` (opcional)

### 4. Inicialização e teste

Inicie o agente:

```bash
python3 hermes_agent.py start
```

Verifique o status:

```bash
python3 hermes_agent.py status
```

O log de inicialização deve exibir: "Hermes Agent running on port 8080".

### 5. Configuração como serviço systemd

Para rodar em background e iniciar automaticamente:

```bash
sudo nano /etc/systemd/system/hermes-agent.service
```

Cole o conteúdo:

```
[Unit]
Description=Hermes Agent Service
After=network.target

[Service]
Type=simple
User=hermes
WorkingDirectory=/opt/hermes-agent
ExecStart=/usr/bin/python3 /opt/hermes-agent/hermes_agent.py start
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Habilite e inicie:

```bash
sudo systemctl daemon-reload
sudo systemctl enable hermes-agent
sudo systemctl start hermes-agent
```

## Instalação passo a passo no Windows

### 1. Preparação do ambiente

Instale o Python 3.8+ baixando do [python.org](https://www.python.org/downloads/windows/). Marque a opção **"Add Python to PATH"**.

Instale o Git para Windows: [git-scm.com](https://git-scm.com/download/win).

### 2. Download via PowerShell

Abra o PowerShell como administrador:

```powershell
git clone https://github.com/hermes-agent/hermes-agent.git
cd hermes-agent
```

### 3. Instalação de dependências

```powershell
pip install -r requirements.txt
```

### 4. Configuração de variáveis de ambiente

Crie o arquivo `.env` manualmente no diretório do Hermes Agent:

```
HERMES_API_KEY=your_key
DATABASE_URL=mssql+pyodbc://user:pass@localhost:1433/dbname
```

### 5. Execução como serviço Windows

Use o `nssm` (Non-Sucking Service Manager) ou crie uma tarefa agendada no Windows Task Scheduler.

Exemplo com nssm:

```powershell
nssm install HermesAgent "C:\Python39\python.exe" "C:\hermes-agent\hermes_agent.py start"
nssm start HermesAgent
```

## Configurações avançadas e otimização

### Integração com ferramentas de produtividade

O Hermes Agent se conecta nativamente com:

- **Slack**: Notificações de erros e alertas em tempo real
- **Jira**: Abertura automática de tickets para falhas
- **APIs REST**: Integração com sistemas legados via endpoints customizados

### Configuração de automações personalizadas (playbooks)

Crie arquivos YAML em `/opt/hermes-agent/playbooks/`:

```yaml
name: "Backup Database"
commands:
  - name: "pg_dump backup"
    command: "pg_dump -U admin dbname > /backups/db_$(date +%Y%m%d).sql"
    on_success: "notify_slack"
    on_failure: "call_admin"
schedule: "0 3 * * *"  # 3:00 AM diariamente
```

### Monitoramento e alertas

Configure métricas customizadas:

```bash
python3 hermes_agent.py metrics --interval 30
```

Alertas podem ser enviados para e-mail, webhook ou log local.

## Troubleshooting comum

### Erro: "ModuleNotFoundError: No module named 'xyz'"

Solução: Certifique-se de que o ambiente virtual está ativado ou que `requirements.txt` foi instalado corretamente.

```bash
pip install -r requirements.txt --upgrade
```

### Erro: "Port 8080 already in use"

Solução: Altere a porta no arquivo `.env`:

```
HERMES_PORT=9090
```

### Erro: "Database connection failed"

Verifique:

- A URL de conexão no `.env`
- Se o banco de dados está acessível e as portas liberadas no firewall
- Autenticação de usuário

## Perguntas frequentes (FAQ)

**1. Preciso de um servidor dedicado?**
Não. O Hermes Agent roda em servidores compartilhados (VPS) com recursos mínimos.

**2. Posso usar sem Docker?**
Sim. A instalação nativa é suportada. Docker é opcional para ambientes isolados.

**3. O agente é seguro?**
Sim. Ele utiliza criptografia TLS para comunicação e tokens de API para autenticação. Consulte a [documentação oficial](https://docs.hermes-agent.io/security) para detalhes.

**4. Quanto custa?**
É open-source, sem custos de licenciamento. Custos de infraestrutura variam conforme provedor.

**5. Como atualizar o agente?**
```bash
git pull origin main
pip install -r requirements.txt --upgrade
python3 hermes_agent.py restart
```

**6. Suporta ambientes com múltiplos núcleos?**
Sim. Escalabilidade é nativa via threads e processos assíncronos.
